Privacy notice

Information about data processing on the DIANAE website and its optional forms. External-provider provisions apply only if those services are enabled.

Data controller

The contact for data protection is Emanuele at info(at)dianae.ch.

How data is used

Personal data may be processed to run the website, respond to enquiries, support optional poll participation and, only where separately requested, send occasional DIANAE updates.

Website visits and hosting

The hosting provider may process technically necessary access information, such as an IP address, access time, requested page and browser details.

Contact form and email

Depending on what you enter, the form may collect a name, email address, how you found us, a message and an optional updates preference. If the external backend is not enabled, it does not automatically submit data to a DIANAE database. Once enabled, submitted messages are stored and may be included in email notifications to info@dianae.ch. Choosing occasional updates does not itself start an automated newsletter.

Online poll

The proposed poll asks for an email address to help prevent repeat voting. Its backend stores a secret-protected cryptographic fingerprint of the email, not the email itself, and processes a protected technical value derived from the IP address for rate limiting. Published results are aggregate totals and are separate from the historical tasting involving 136 people.

Service providers and international processing

When configured, Cloudflare is intended to provide the API and database, while Resend sends notification emails. Before activation, the actual providers, processing locations and any appropriate safeguards for international transfers must be verified.

Retention, security and rights

The planned database has no automatic deletion period yet. A reasonable retention and deletion policy must be set and implemented before collecting live submissions. Subject to applicable law, you may request access, correction, deletion and other rights via info(at)dianae.ch.
